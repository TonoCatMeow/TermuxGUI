Security notes

  • This server runs as root inside the proot-distro Debian container. Every app, workflow and terminal session executes with root privileges — that is the deploy/workflow feature by design, and the access token is the only gate.
  • Traffic is plain HTTP on your LAN. Apps bind 0.0.0.0, so any port you assign is reachable by every device on the network — only assign ports you mean to share.
  • Login is rate-limited (5 tries / 60s lockout) and the token is compared in constant time.
  • proot is not a hard security boundary: paths bound from Termux/Android shared storage are reachable from inside the container.
