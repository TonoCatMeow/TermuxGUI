Save / replace tunnel token

One-time setup: in the Cloudflare Zero Trust dashboard, create a named tunnel, add a Public Hostname on your domain (e.g. deploy.yourdomain.com → localhost:8080), and copy the tunnel's token. Paste it here once — it is stored in state.json and never shown again.
cloudflared is not in Debian's repos — install the ARM64 .deb as root: curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb -o /tmp/cf.deb && dpkg -i /tmp/cf.deb

Security notes

  • This server runs as root inside the proot-distro Debian container. Every app, workflow and terminal session executes with root privileges — that is the deploy/workflow feature by design, and the access token is the only gate.
  • Traffic is plain HTTP on your LAN by default. Prefer using it over the Cloudflare tunnel (HTTPS on your own domain) when away from home.
  • Login is rate-limited (5 tries / 60s lockout) and the token is compared in constant time.
  • The Cloudflare tunnel token is a secret too — it is stored in state.json (mode 600) and never echoed back in full.
  • proot is not a hard security boundary: paths bound from Termux/Android shared storage are reachable from inside the container.
